## 原因和范围

业务库 `web/table_material_columns.mjs` 的 `fillMaterialColumn` 原先只遍历输入素材数组，单素材只改第一行；适配器预览也只取前 `count` 个单元格。画布的拖入来源原先仅包含上传节点和素材组，文本快照未接入。

- 单条图片、视频或文本覆盖目标列的现有行；空表增加一行。多个素材继续按序填入，保留未涉及的尾部行。图片／视频每行独立标识，重复填入相同文件保留该行已有标识。
- 复用现有 `fillMaterialColumn`、`setValue`、编辑器事务和宿主撤销机制；没有新增控件或样式。
- 画布通过公开 `inputSnapshot` 接收文本，接收方用可选 `accepts` 声明能力，旧接收方仍只接收图片／视频。宿主只负责快照、类型命中和预览；填充规则仍归业务库。
- 保留单格素材追加和行头横向填充；不修改槽位、素材 JSON 或工作流存储格式，不调用生成服务。
