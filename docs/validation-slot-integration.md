# Slot 基准与本地面板整合验证 · 2026-09-29

## 交付范围

以已合并 PR #1 的 `a5c14ae` 为基础，整合本地 `4c55cfc` 的表格外框缩放、完整内容高度和素材组填充。保留 PR #1 的剪辑节点、Slot 显隐、磁吸、连线端点跟随与接收端拖开断线。

共享入口为 `web/creative_canvas_view.mjs`、`web/creative_connections.mjs`、`web/creative_canvas.css` 和 `web/creative_theme.css`。节点通过公开适配器接入；业务库和 ComfyTV 未修改。

冲突处理同时保留正向／反向缩放 CSS 变量、不可收起节点、可调整宽度／紧凑面板，以及 ResizeObserver 和宽度拖动的释放。磁吸起拖命中接口外层时，使用独占事件处理，防止素材组的捕获监听器同时开始整组拖动。

## 本次验证

在同一台 Windows 机器的两个隔离 CPU 服务中进行，使用真实 ComfyUI 前端、合成的两张本地图片及独立用户目录，没有重启主服务或执行付费生成。

## 剩余边界

- 本轮不是全量交互验收。尚未穷尽长内容、菜单边缘、多个接收线的候选选择、反向连线、减少动态效果及所有取消路径。
- 剪辑断线同步占用额外撤销步骤，需后续将连接变化与衍生时间轴更新合并到同一历史边界；本次不修改剪辑异步历史机制。
- PR #1 的半帧边界前后端取整差异已由维护者接受，本次未修改；未重新验证所有视频编码／预览倍率组合。
- 联合安装使用当前本地业务库的公开适配器能力；本 PR 不交付业务库改动。另一台机器仍需安装提供这些能力的业务库版本。
