# 资产库与底部工具栏

按已选定的「底部抽屉」实现。2026-10-21 双库整合后的实际验证见 [validation.md](validation.md#双库-pr-本地整合--2026-10-21)；下方保留首次实现的验收记录。

- 画布宿主拥有底部「新建」「资产库」入口；新建复用已注册节点菜单，抽屉固定屏幕尺寸，不随画布缩放。
- 图片、视频、输入文本提供收藏按钮。收藏为内容快照：文本保留当时的内容；媒体保留原本地文件引用，不复制文件或保存临时远程 URL。取消收藏不删除文件和已创建节点。
- 首版以当前服务地址下的浏览器 localStorage 保存版本化目录；刷新和浏览器重启保留，切换浏览器、端口或清理站点数据不共享。界面明确标注此范围。文件移走或失效时显示错误，不创建空素材。
- `asset_library_model.mjs` 负责校验、去重和持久化；`asset_library.mjs` 负责抽屉及预览；宿主注入新建、加入画布回调。公共按钮、字段、主题和节点活动模式沿用现有实现。
- 本功能不增加业务生成依赖、不访问业务面板私有状态，不修改既有 slot、material JSON 和 `daelabCreativeCanvasV1` 格式。新建素材通过宿主历史事务，可撤销。抽屉与预览的选择状态不写入工作流。
- 画布隐藏时关闭预览、暂停视频并折叠抽屉；节点停用时其收藏入口随自有面板关闭。订阅、事件、媒体和按钮绑定随实例销毁释放。

验收：双素材实例隔离、收藏去重/取消/恢复、文本快照、图片/视频预览、失效文件、保存重载、撤销、画布/原生模式往返、Active/Mute/Bypass、50/100/150% 缩放、窄窗口及焦点；独立 Canvas 与可选业务库组合安装分别检查。具体实际验证结果另行记录。
