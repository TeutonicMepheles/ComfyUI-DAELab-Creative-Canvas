# 前端与交互规范

本文件是创作画布前端的视觉与交互约定，依据 2026-09-28 已验收的素材上传、编组调整整理。适用于本仓库拥有的界面；不授权修改 ComfyTV、原生 ComfyUI 或业务库的旧展厅／徽章 App Mode。

## 按任务阅读

不要求每次任务通读所有章节。先定位任务，再阅读通用基线、对应章节和验收要求；跨范围任务取并集。

| 任务 | 必读章节／关联文档 |
| --- | --- |
| 安装、运行环境、纯后端且不改变界面契约 | README 环境指南；无需加载本文件细节 |
| 颜色、字体、图标、布局、控件状态 | 通用视觉基线、缩放与容器、验收 |
| 上传、缩略图、标题、素材操作 | 通用视觉基线、缩放与容器、素材节点、验收 |
| 编组、排列、颜色、序号、删除 | 通用视觉基线、缩放与容器、素材组、接口与连线、验收 |
| 选择、拖动、Slot、连线动画 | 拖动与选择、接口与连线、验收 |

本文件定义产品行为；控件开发契约定义实现边界；[素材组说明](../material-groups.md)定义执行数据契约与测试入口。避免在这些文件重复维护同一套规则。修改已验收行为时，应明确说明变化并同步本文件；不能仅因重构而改变体验。

## 通用视觉基线

- 使用 Material Design 3 语义颜色、字阶、形状和交互状态，密度适配桌面创作工具。复用 `web/creative_theme.css` 与共享按钮／字段，禁止节点各自复制一套颜色和尺寸。
- 样式限定在 `.dae-creative` / `.dae-ui`，不全局覆盖原生标签或其他插件。悬浮、选中、键盘焦点、禁用、忙碌和错误状态应可区分；保留焦点轮廓。正文对比度目标至少 4.5:1，必要控件边界至少 3:1。
- 中文和混排使用本地打包的 Alibaba PuHuiTi 3.0、`--dae-font-family`。常规正文 400、标题和控件 500、强调 600；默认正文 14px、节点标题 16px、辅助信息 12px。组标题可适度放大。复用原始 WOFF2，不依赖系统安装或在线字体，保留许可证和 SHA-256 清单。
- 本仓库优先使用已打包 Remix 图标，保持尺寸、风格一致。熟悉的紧凑操作使用图标按钮，需可访问名称和可发现提示；不明确的操作保留文字。不同含义避免复用令人混淆的图标，例如排列与序号。
- 方案审阅基于实际 ComfyUI 框架与画布。辅助陈列可用于控件检查，但不能替代产品验收。正式交付清除示例加载条、Demo 保存／恢复、调试说明等临时界面。

## 缩放与容器

- 标题文字、图标及悬浮操作控件保持稳定的屏幕视觉尺寸，媒体内容和布局随画布缩放。区分屏幕像素与画布坐标；不得只补偿字号而遗漏图标、间距、命中区域和定位。
- 缩小到空间不足时隐藏操作控件，不能让固定尺寸按钮溢出。当前素材操作阈值为缩略图屏幕宽度 160px，判断入口在 `web/material_groups.mjs`；低于阈值，即使选中也隐藏操作按钮。
- 容器由内容与实际交互需要决定。隐藏信息不保留无意义的大块空间；菜单应贴近对象并保持在可用视口中。文本、媒体、菜单、提示和焦点轮廓均需检查溢出；不能用任意固定高度或统一裁切掩盖布局错误。
- 具体视觉数值以共享主题和拥有该行为的实现为维护入口。本文件中的数值是验收基线，不要求在每个节点复制常量。

## 素材节点

- 空缩略图默认 16:9，与机器屏幕比例无关。上传后按素材原始宽高比显示并填充节点宽度，不拉伸、不擅自裁切，也不以固定高度制造宽黑边。
- 素材标题直接展示在缩略图上方，与缩略图左边缘对齐；不另套标题圆角卡片。图标与文字间距紧凑，标题不压过组名的层级。
- 孤立素材和素材组均支持双击标题重命名；Enter 保存、Escape 取消，中文输入法组合输入期间不误提交。拖动处理不能吞掉标题双击。
- 组内素材未选中时隐藏名称控件，优先展示缩放适应后的组名；选中成员再显示其标题。
- 替换、下载、全屏使用相同尺寸、形状和间距的圆形图标按钮，仅选中时在缩略图右上角显示，并受小尺寸阈值约束。不可用／隐藏的按钮不留空位，其余按钮向右对齐。
- 文件名和分辨率在缩略图内部左下角显示，仅悬浮或选中时可见。文字带底纹，长内容省略并可通过提示读取完整信息；底纹受缩略图圆角边界约束，不能溢出。
- 空态保持简洁，不添加“每个上传节点承载一份素材”等冗余说明。视频控件保留正常播放操作。

## 素材组

- 组选中后使用原位横向工具栏，不展开大型信息侧栏。组需具备清楚的悬浮与选中反馈。
- 宫格、水平、垂直自动排列应紧凑。当前成员间距为 6 个画布像素，布局入口在 `web/material_groups.mjs`。容器随内容收紧；成员名称隐藏后不能继续预留整段标题／信息栏高度。
- 五个常用色块及通用选色器入口直接位于横向工具栏，色块为正圆，避免被 padding 或最小宽高挤成胶囊。自定义颜色即时更新边框与容器淡色背景，并在工具栏提供对应颜色选项；不以标题旁矩形色条代替组颜色。
- “序号”是独立显隐开关。序号叠加在缩略图左上角，采用圆形底板；底板与工具栏序号选中态使用一致、清晰的颜色体系。序号与排列使用不同图标。
- 组选项包含收起／展开、锁定／解锁、重命名、解散等行为，文字配对应图标。锁定阻止整组及成员移动和排列变更。
- “删除组”是横向工具栏的最后一项，使用红色文字、图标和淡红底纹。删除组删除容器、成员及相关连线；解散组只解除组关系并移除容器及其连接，保留成员节点。两者不可混淆，支持撤销。
- 整组输出明确表示有序的完整素材集合，成员顺序与输出顺序一致。多维表格填充仍待专门设计，不加入正式菜单，不隐式把组转换为表格列。当前只支持上传素材成员，不支持嵌套组。

## 拖动与选择

- 节点标题、缩略图及节点主体都可作为拖动区域，不限制为标题栏。按钮、输入框、菜单及视频播放控件保留自己的交互。
- 保留已有中键平移、空白框选、Shift 追加选择、滚轮导航和 Ctrl 缩放习惯。共享控件的文字编辑不被画布快捷键抢占。
- 组内素材支持从外部拖入、移出、重排；移动组带动成员。点击选中与实际拖动应区分，拖动取消和撤销恢复原有位置及组关系。
- 相邻缩略图不得遮挡选中成员的操作控件和 Slot；提高交互层级时不能阻挡菜单或无关节点。

## 接口与连线

| 对象／状态 | Slot 行为 |
| --- | --- |
| 孤立素材 | 保留节点悬浮时的接口交互；显隐不改变真实槽位 |
| 素材组 | 悬浮显示、离开悬浮隐去；位于组左右侧中部 |
| 组内未选中素材 | 即使悬浮也不显示单节点 Slot |
| 组内已选中素材 | 显示其 Slot，同时隐藏所属组 Slot |
| 收起的组 | 隐藏成员不能压制容器接口；组恢复自己的接口规则 |

- 隐藏的 Slot 不参与点击和磁吸命中。可见性必须和交互命中一致，不能只设置透明度。
- 既有组连线始终锚定组边框侧面中点，即使 Slot 悬浮出现，也不改接到外侧圆形按钮上。
- 选中有关联连线的素材或组时，脉冲从上游向下游移动。采用较慢移动、多个脉冲同时可见的效果；缩放、平移和路径重绘保持动画相位，不从头播放。减少动态效果偏好下使用静态高亮。
- 连线视觉不改变原生类型化输入输出，不通过伪造接口绕过兼容校验。整组输出与单素材输出必须保持语义区别。

## 验收

每次前端逻辑、布局或样式变更都在真实 ComfyUI 检查受影响区域；至少使用两个实例验证数据独立性，覆盖模式切换、保存后刷新重载和相关缩放级别。涉及集成时同时检查独立安装与联合安装。

按任务补充以下场景，不要求纯文档任务重新跑全部交互：

- 素材：空态、不同媒体比例、长文件名、视频、两个不同宽度；操作按钮阈值上下、圆形和等间距、底纹圆角无溢出。
- 标题：孤立节点与组双击、中文输入、取消、保存重载；组内选中切换时的名称显隐与左对齐。
- 组：三种排列、紧密相邻、拖入／移出、锁定、收起／展开、改色、自定义色、序号切换、删除与解散及撤销。
- 接口：组和成员选中切换、多个组互不干扰、隐藏接口不可磁吸、选中成员接口不被相邻节点遮挡、连线锚点不跳动。
- 动画：方向、多个脉冲、缩放过程中连续性、减少动态效果。
- 通用：悬浮／焦点／禁用／忙碌／错误，长内容和边缘菜单，无意外空白、裁切或重复滚动条。

检查实际渲染截图并操作相关状态。单元测试、构建或 CSS 断言不能替代视觉验收；环境受限时明确报告未验证项。禁止为了验收擅自发起付费生成。
