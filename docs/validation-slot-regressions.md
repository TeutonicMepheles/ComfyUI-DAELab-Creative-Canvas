# Slot 与素材操作回归检查 · 2026-09-29

基于 PR #2 合并后的 `dca89ff`，本次修复两个独立问题：

- 共享画布接口增加邻近光标微动。命中计算扣除当前偏移，限制在 6 屏幕像素内；离开、缩放、连接结束与取消清理偏移，减少动态效果时不微动。普通控件的 pointerup 不再清除当前悬停状态。

## 实际验证

- 独立 ComfyUI CPU 服务：两个上传实例分别选中，均显示替换、下载和全屏；非选中实例保持隐藏。第二实例实际替换图片，第一实例保持原引用。
- Slot 在 50% 和约 98% 缩放下测得朝光标方向的实际位移，量级约 4–5 屏幕像素；微动后仍可拖线连接。检查了约 40%、50%、98%、153% 的实际截图，按钮维持 36 屏幕像素，画布可平移浏览。
- 图形／创作画布往返、保存工作流后刷新，素材引用、已连接片段与素材操作按钮恢复。
- 修复前的对照检查：独立服务中图片直接连接、新建上传节点后上传测试视频并连接，均立即出现片段。主服务的新页面中，本地视频直接连接也立即出现片段；随后新建的空上传节点显示“上传”，没有继承先前文件名。
- 自动检查：17 项 Node 测试、三份字体 SHA-256 校验、修改 JS 语法与差异格式检查通过。这些单元测试不覆盖浏览器微动；以上微动结果来自真实页面检查。
