# 正式素材组

素材组已进入普通创作画布，不依赖 URL 开关、Demo 本地存档或临时运行拦截。示例加载条、审阅启动按钮及未启用的表格填充代码已移除。多选上传素材后使用左上角“素材打组”或 Ctrl+G；也可在 Comfy 命令中搜索“选中素材打组”。

视觉细节、Slot 显隐与审阅验收规则统一维护在 [前端与交互规范](architecture/FRONTEND_INTERACTION.md)，按任务阅读对应章节。

## 用户行为

- 宫格、水平、垂直排列，6 个画布像素间距。拖动组标题或空白区域移动整组；素材缩略图、空预览和标题都可以拖动，支持移出／加入／重排。按钮、输入控件和视频底部播放控件保留操作。空预览始终为 16:9，与屏幕尺寸无关。
- 组名使用统一节点字体，显示在容器外侧上方。组内拖动排序显示虚线占位框，其他素材预先让位；水平／宫格按目标左、右半边选择前后，垂直排列使用上、下半边。松开后同步序号与整组输出顺序，取消则恢复；可撤销，保存工作流后保留。
- 原位菜单支持五种常用颜色、自定义颜色、序号、收起、锁定、重命名、解散、删除。锁定后不能移动成员或改变排列。仅支持本扩展上传节点作为成员，不支持嵌套组。
- 解散只移除容器及它的连接，保留成员；删除组移除容器、成员和相关连接。复制组包含成员及内部连线，粘贴后成员 ID 重映射，不指回原组。
- 普通 Comfy 工作流保存、重载和原生撤销／重做管理这些操作。DOM 修改使用 `creative_history.mjs` 适配当前 Comfy workflow changeTracker；未另建 Demo 撤销栈。
- 选中时使用屏幕尺寸固定的圆形素材操作按钮，缩略图屏幕宽度低于 160px 时隐藏。名称、序号、颜色、元信息遮罩和悬浮 Slot 使用审阅通过的样式。
- 线条锚点始终在组侧面中点。选中相关节点时，五段脉冲沿线流动；穿越全线约五秒，缩放重绘保留相位。减少动态效果偏好下为静态高亮。
- 离开创作画布时归还原生媒体面板，恢复其文本按钮和信息位置。

## 执行与扩展契约

稳定节点 ID 为 `DAELAB.MaterialGroup`，输出为 `DAELAB_ASSETS`，值为 `{version:1, assets:[...]}`。按成员顺序提交素材快照，保留素材 id、nodeId、kind、filename、subfolder、name；后端验证本地文件并补充 `/view` URL。空组输出空数组；缺失项保留位置标记，只有消费这个组时才报错，不阻止其他无关工作流导出。

这是有序的整组图片／视频集合，不隐式转换成单张图片、图片张量或表格列。表格填充及其业务映射按约定留待后续实现。消费者应明确声明 `DAELAB_ASSETS` 输入并读取其版本化结构。

原 `DAELAB.GroupReviewDemo` 工作流在载入时迁移为正式节点，保留成员、布局和颜色。Demo 人为加到表格上的审阅输入与对应假连线会移除；表格记录保留。没有修改业务库或 ComfyTV。

## 验证

- `npm test`：16 个测试，包括有序集合、缺失项、复制关系和旧数据迁移。
- `npm run verify:assets`：原始字体 SHA-256 检查。
- `COMFY_URL` 指向隔离的普通 Comfy 页面后运行 `node tools/material_groups_smoke.cjs <截图目录>`。测试独立及联合安装，两组实例、颜色独立性、展开收起、锁定、原生撤销重做、复制删除、整组移动／跨组拖动及撤销、模式切换、保存 JSON 后刷新载入、30%/100%/200% 缩放、脉冲和减少动态效果。脉冲用例的目标输入仅由测试临时添加，不宣称表格填充验收。
- `python tools/material_groups_backend_smoke.py --comfy-root <ComfyUI源码目录> --input-directory <input目录>`：实际后端混合图片／视频集合、空组和缺失文件。需要测试夹具 `DAELAB/group-review-demo/mountain.png` 与 `motion.webm`，与浏览器用例相同。
- 本轮在本机 CPU 服务 8207（含业务库）及 8208（仅画布扩展）验证。未运行付费生成，也不代表第二台物理设备验收。
