# 独立仓库迁移

## 来源

源仓库：`TeutonicMepheles/ComfyUI-DAELab-Custom-Nodes-Library`。
代码从本地已验证提交 `d9270fa` 的创作画布文件提取，其对应的远端功能增量为 PR #19 的 `8bd730d`（已合并进 #18）。#18 迁移前远端基线为 `a3df376124786d5ba5a6d053c0f8c12a8e921dba`。

只提取画布、上传、共享控件、辅助陈列、相关测试和静态示例；没有带入本地工作流、用户素材、缓存、访问令牌或上游 ComfyTV 源码。可重复安装使用 Git 仓库根目录，忽略的 node_modules/dist 不是运行依赖。

## 升级顺序

配套业务库变更：[PR #20](https://github.com/TeutonicMepheles/ComfyUI-DAELab-Custom-Nodes-Library/pull/20)，迁移提交 `ee0d463af3cb09cc14e0e03ec0d2787d1a6f3762`。该 PR 基于 #18，尚未合入业务库默认分支；在其合并前，请使用这个迁移分支，不能只更新业务库 main 后就假定已兼容。已验证的画布代码基线是本仓库初始提交 `2323e91`。

1. 保存当前工作流 JSON。关闭 ComfyUI 前完成正常任务。
2. 安装本仓库，并将业务库更新至“拆分创作画布仓库”的迁移 PR 或其后继版本。两个目录一次性更新，不在半迁移状态启动。
3. 重启 ComfyUI，刷新浏览器，重新打开工作流。无需改节点 ID、素材路径或工作流 JSON。

只运行上传与画布时，可不安装业务库和 ComfyTV。原生上传图像／视频执行已单独验证。业务库自身不依赖画布：移除画布后其表格、LibTV 等原生节点仍存在，但含上传节点的工作流需要重新安装画布。

旧版业务库内置 `DAELAB.MediaUpload` 及画布入口，与新仓库不是受支持的组合。必须更新业务库，避免 Python 映射覆盖和前端重复入口。当前迁移将旧入口文件和上传 Python 实现移除，只保留 `creative_canvas_adapter.js`；旧主题地址用一行 CSS 转发到新所有者。业务库徽章使用的 Remix 静态资源保留，不因拆仓产生新运行依赖。

## 回滚

保存工作流；停服务；将新仓库目录移出 `custom_nodes`，业务库恢复到迁移前提交；重启并重开工作流。不要同时启用两套上传节点实现。数据格式没有变化，素材仍在 ComfyUI input/DAELAB/uploads，不随仓库迁移或回滚移动。

## 版本责任

画布拥有共享交互、主题和基础素材节点，业务库拥有表格／分镜／LibTV 服务及其 v1 适配器。新增编组功能应在画布仓库开发。适配器契约稳定后可以独立发布；更改契约时必须同时检查 standalone 和 combined 两种安装，记录兼容版本。
