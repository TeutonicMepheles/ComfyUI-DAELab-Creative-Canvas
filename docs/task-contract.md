# 节点任务展示接口 v1

业务执行 → 业务所有者汇总 → adapter.tasks(node) → 公共校验/格式化 → 公共胶囊。

`tasks(node)` 返回数组，空数组表示没有可展示任务。字段：

| 字段 | 含义 |
| --- | --- |
| id / label | 必填稳定任务类别标识 / 简短名称；id 在同一节点内唯一 |
| state | queued / running / paused / cancelled / error / recovery / success |
| detail | 业务提供的阶段或异常简述，纯文本 |
| done / total / countLabel / unit | 可选真实计数；如 8 / 20 / 已结束 / 行；不可把已结束伪装成成功 |
| progress | 可选真实 0–100 百分比；多并行任务不能把某一行百分比当成整体百分比 |
| startedAt / elapsed | 可选本次等待起点（毫秒时间戳）/ 是否显示等待秒数 |
| finishedAt | 成功或取消发生时间；4 秒后隐藏。缺失代表历史结果，不弹完成通知 |
| order | 可选稳定顺序，默认 100，相同顺序按 id 排序 |

公共模块 `web/creative_tasks_model.mjs` 与 `web/creative_tasks.mjs` 不引用 app、节点类型、业务属性、后端或模型；样式统一在 `creative_tasks.css` 并复用主题、字体和 Remix 图标。画布宿主只调用适配器接口，复用已有 250ms 同步，不建立每节点计时器。业务库不用安装 Canvas 即可独立运行。

同类行任务由业务方聚合，优化/图片/视频分别成条。运行时状态不得放进 node.properties、widget、撤销历史或工作流。提供者负责请求身份、过期结果、恢复和取消；控件只展示，绝不由隐藏、消退、停用或销毁胶囊取消业务。刷新只显示有依据的恢复状态，不把历史 running 当作新的执行证据。

胶囊在标题上方向上堆叠，不参与节点尺寸、连线锚点或表格布局；标题和胶囊共同跟随节点。胶囊保持单行，长详情省略；标题可用宽度不超过 240px 时只显示状态图标和任务名称，不超过 110px 时隐藏胶囊，放大后恢复，错误/暂停带明确文字与图标，减少动态效果时停止旋转。没有任务不留空白；移除卡片释放胶囊 DOM。节点停用遵循现有卡片显示规则，不虚构任务暂停。

基础上传/剪辑由基础节点自己的适配器提供快照；表格、解析器、提示词优化、LibTV 的映射归业务库。已有任务详情和控制保持在原面板，这一版胶囊只读。
